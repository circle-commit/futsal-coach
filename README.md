# 풋살 코치

드론으로 위에서 찍은 풋살 수업 영상을 **브라우저 안에서** 분석해 아이마다 뛴 거리·속도·위치·공 터치·패스를 보여 주는 웹 앱이에요. 영상은 서버로 올라가지 않아요.

바로 쓰기: **https://circle-commit.github.io/futsal-coach/** (크롬·사파리 최신 버전)

## 직접 띄우기
```bash
npx http-server . -p 8772 -c-1
```
http://localhost:8772 을 열면 돼요. 워커(모듈)와 영상 구간 이동 때문에 `file://`로 직접 열면 안 되고, 위처럼 서버로 띄워야 해요.

## 쓰는 순서
1. **새 수업 분석** → 영상 고르기
2. 코트 라인 네 모서리를 왼쪽 위부터 시계 방향으로 누르고, 실제 코트 크기(m)를 넣기
3. 팀마다 그 팀 아이를 한 명씩 누르기 (팀별 인원은 적어도 되고, 비우면 자동)
4. 분석 (5분 영상 약 1분 40초, 탭을 연 채로)
5. 결과 화면에서 카드의 이름 칸으로 **아이 명단**과 연결 → 아이별 수업 기록이 쌓여요

기록은 브라우저(IndexedDB)에만 저장돼요. 홈 화면의 **백업 파일 받기**로 가끔 내려받아 두세요.

## 구조
- `js/vision.js`: 픽셀 처리 (배경 빼기, 조끼 색, 공 후보, 호모그래피)
- `js/track.js`: 고정 인원 추적(헝가리안), 활동량, 공 경로(비터비), 공 소유·패스
- `js/pipeline.js`: 설정 → 검출 설정, 검출 → 결과
- `js/analyzer.js`·`js/worker.js`: 영상을 빠르게 재생하며 프레임을 워커 여러 개에 나눠 분석
- `js/new.js`·`js/session.js`·`js/app.js`: 화면
- `tools/analyze.mjs`: 같은 분석 코드를 node + ffmpeg로 돌리는 검증 도구

## 한계
- 드론이 한자리에 떠 있어야 해요 (카메라가 움직이면 배경 빼기가 깨져요).
- 공 지름이 화면에서 8~12px이라 공 위치·패스는 베타예요. 몸과 떨어진 흰 덩어리는 공, 다리에 붙은 흰 점은 양말·발밑 공으로 보고 영상 전체에서 이어지는 경로를 골라요. 샘플 8장면 중 6~7곳이 맞았어요.
- 분석 중 다른 탭을 보면 잠시 멈추고, 끝난 뒤 놓친 장면은 하나씩 찾아가 채워요(그만큼 느려짐).
- 같은 팀 아이가 겹쳤다 떨어지면 번호가 바뀔 수 있어요.
- `samples/sample.mp4`는 실제 아이들 영상이라 공개 배포에 포함하면 안 돼요.
